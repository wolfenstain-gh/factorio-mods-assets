# FAQ

**Who is this for?**
For casual players who want a more relaxed factory. It's an "easy mode": it doesn't try to fix the base game, which I think is great as it is.

**Do I need Space Age?**
Yes, it requires Space Age.

**Does it work with other mods?**
It's applied on top of the base game and other mods, and every change is guarded: if an item doesn't exist, that tweak is simply skipped.

**Can I add it to an existing save?**
Yes. The new recipes and values apply as soon as you load the save.

**Can I remove it later?**
Yes, the game goes back to the vanilla recipes and values.

**Will it work with Factorio 2.1?**
Yes, it will be updated when 2.1 is out as stable.

**Something doesn't work / I have an idea.**
Please post it in the **Discussion** tab. Thanks!
