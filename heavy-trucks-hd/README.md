# Heavy Trucks (Vanilla+): HD graphics

**[Download it on the Factorio Mod Portal](https://mods.factorio.com/mod/heavy-trucks-hd)** · Factorio 2.0

Optional high-resolution graphics for Heavy Trucks (Vanilla+): the trucks as they were rendered, at twice the resolution of the standard ones. Heavy Trucks uses them automatically when this mod is enabled; nothing else changes.
